# Jivora By Stuti — Media Asset Upload Guide

Place your original brand media files inside `public/assets/` using the exact paths below. Missing assets are handled gracefully with luxury placeholders until uploaded.

1. **Original Logo**: `public/assets/logo/logo.png`
2. **Hero Banner 1**: `public/assets/banners/hero-banner-1.jpg`
3. **Hero Banner 2**: `public/assets/banners/hero-banner-2.jpg`
4. **Hero Banner 3**: `public/assets/banners/hero-banner-3.jpg`
5. **Main Video 1**: `public/assets/videos/main-video-1.mp4`
6. **Main Video 2**: `public/assets/videos/main-video-2.mp4`
7. **Main Video 3**: `public/assets/videos/main-video-3.mp4`
8. **Main Video 4**: `public/assets/videos/main-video-4.mp4`
9. **Three Showcase Photographs**:
   - `public/assets/showcase/photo-1.jpg`
   - `public/assets/showcase/photo-2.jpg`
   - `public/assets/showcase/photo-3.jpg`
10. **Category Video**: `public/assets/videos/category-video.mp4`
11. **Featured Section Video**: `public/assets/videos/featured-video.mp4`
12. **Footer Video**: `public/assets/videos/footer-video.mp4`
13. **Category Photographs**: `public/assets/categories/<category-slug>.jpg` (e.g. `necklaces.jpg`, `rings.jpg`, `mens-watches.jpg`)
14. **Product Photographs**: `public/assets/products/<PRODUCT-ID>/main.jpg`
15. **Product Gallery Photographs**: `public/assets/products/<PRODUCT-ID>/gallery-1.jpg`, `gallery-2.jpg`
16. **Customer Photographs**: `public/assets/customers/<filename>.jpg` (referenced in `src/data/reviews.ts`)
